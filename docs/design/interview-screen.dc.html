Problem

Merge Meeting Slots

Medium Arrays Sorting

You are given a list of meeting slots, where each slot is a pair [start, end]. Merge every group of overlapping slots and return the remaining non-overlapping slots, sorted by start time. Slots that only touch at an endpoint count as overlapping.

Example 1
Input: [[1,3],[2,6],[8,10],[15,18]]
Output: [[1,6],[8,10],[15,18]]
Example 2
Input: [[1,4],[4,5]]
Output: [[1,5]]
Constraints
  • 0 <= slots.length <= 104
  • 0 <= start <= end <= 106

def merge_slots(slots):
# sort by start so overlaps sit side by side
slots.sort(key=lambda s: s[0])
merged = [slots[0]]
for start, end in slots[1:]:
last = merged[-1]
if start <= last[1]:
last[1] = max(last[1], end)
else:
merged.append([start, end])
return merged
